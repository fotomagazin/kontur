# Контур

**Векторный редактор прямо в браузере.** Один файл — без установки и регистрации. Для макетов к печати и резке, вывесок, наклеек, логотипов и QR-кодов.
Перо и кривые Безье, фигуры, текст с 16 шрифтами (с кириллицей) и превращением в кривые, сложить / вычесть / пересечь / исключить, выравнивание и распределение, линейки, направляющие, сетка и привязка, обводка фото и логотипов, векторные QR-коды. Размеры в миллиметрах. Сохранение в SVG, PDF, EPS, DXF и PNG.

## Как запустить

1. Скачайте архив и распакуйте его — получится папка «Контур».
2. Откройте в ней `kontur.html` двойным кликом — программа запустится в браузере (лучше всего в Chrome или Edge).
3. Рисуйте пером или фигурами, напишите текст или перетащите в окно фото, чтобы обвести его.

## Что в репозитории

- `kontur.html` — сама программа (HTML + CSS + JavaScript в одном файле).
- `Как пользоваться.txt` — инструкция, которая кладётся в архив вместе с программой.
- `tools/` — служебные скрипты: сборка архива для скачивания, автоматическая проверка программы в Chrome.
