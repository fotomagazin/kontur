# Контур

**Векторный редактор — программа для Mac и Windows, а ещё браузерная версия в одном файле.** Бесплатно и без регистрации. Для макетов к печати и резке, вывесок, наклеек, логотипов и QR-кодов. Работает без интернета.
Перо и кривые Безье, фигуры, текст с 16 шрифтами (с кириллицей) и превращением в кривые, сложить / вычесть / пересечь / исключить, выравнивание и распределение, линейки, направляющие, сетка и привязка, обводка фото и логотипов, векторные QR-коды. Открывает файлы Illustrator (.ai) и PDF — кривыми. Размеры в миллиметрах. Сохранение в SVG, PDF, EPS, DXF и PNG.

## Как запустить

- **Mac:** откройте `.dmg` и перетащите «Контур» в «Программы».
- **Windows:** запустите `Kontur-windows-setup.exe` — программа установится сама, ярлык появится на рабочем столе.
- **Браузер:** распакуйте `kontur.zip` и откройте `kontur.html` двойным кликом (лучше всего в Chrome или Edge).

Дальше — рисуйте пером или фигурами, напишите текст или перетащите в окно фото, чтобы обвести его.

## Что в репозитории

- `web/kontur.html` — сама программа (HTML + CSS + JavaScript в одном файле). Это и есть браузерная версия; из неё же собираются программы для Mac и Windows.
- `web/Как пользоваться.txt` — инструкция, которая кладётся в архив вместе с программой.
- `mac/служебное/` — программа для Mac (Electron): окно, меню, открытие файлов из Finder, сохранение прямо в файл, работа без интернета.
- `windows/служебное/` — программа для Windows (Electron): то же самое, установщик в один щелчок.
- `tools/` — служебные скрипты: сборка архива для скачивания, автоматическая проверка программы в Chrome.
